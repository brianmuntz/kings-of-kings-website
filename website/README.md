# Kings of Kings International

Independent website rebuild. Development preview: http://localhost:8090/

The original site and backup are unchanged. This project contains editable HTML, CSS and JavaScript, local fonts and images, 15 content/error pages, plus the legacy-home redirect and root 404 document. No WordPress or model runtime is needed.

Run `python3 tools/preview.py` from this folder. Stop with Ctrl+C. The preview binds to this computer only and returns noindex headers. Use Pinegrow to open this folder, or continue editing through the project agent. The same HTML files power the preview.

Read SEO-REVIEW.md for verification and remaining launch work. Deployment and Orange access are not configured. No subscriptions or paid services were purchased.
